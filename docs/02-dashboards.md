# Дашборды, папки и главная страница

## Папки

| Папка | Назначение |
|---|---|
| Инфраструктура | хосты, сеть, диски, Prometheus |
| Сервисы | доступность сервисов, контейнеры, алерты, Zabbix |
| Логи | Graylog и Loki |
| Безопасность | события безопасности |

«Обзор лаборатории» лежит в корне и назначен главным дашбордом организации (Administration → Default preferences → Home Dashboard).

## Принципы

- **Русские названия** дашбордов и секций (row): их читает человек, который открывает панель утром, а не инженер Grafana.
- **Один вопрос — один дашборд.** «Парк хостов» отвечает «всё ли живо», «Детали хоста» — «что происходит на конкретном хосте» (переменная `$instance`).
- **Пустых панелей быть не должно.** Если данных нет, панель либо убрана, либо подписана так, что пустота понятна («Что не отвечает» пуста, пока всё в порядке).
- **Фиксированные uid** (`ds-*`), чтобы ссылки между дашбордами не ломались при повторном импорте.
- Каждый дашборд подключает аннотации Graylog (см. [03-annotations.md](03-annotations.md)), поэтому алерты видны на любом графике.

## Импорт

```bash
for f in dashboards/*/*.json; do
  jq '{dashboard: ., overwrite: true, folderUid: "<uid папки>"}' "$f" |
  curl -s -u admin:*** -H 'Content-Type: application/json' -X POST https://grafana.example/api/dashboards/db -d @-
done
```

Либо через provisioning ([../provisioning/dashboards.yml](../provisioning/dashboards.yml)): с `foldersFromFilesStructure: true` папки создадутся по каталогам.
